## 📖 Proje Hakkında

Günümüzde her yıl tonlarca gıda israf ediliyor. **Gıda Köprüsü**, bu israfın önüne geçmek için hem web hem de mobil (React Native/Expo) platformlarda çalışabilen modern bir uygulama olarak tasarlandı. Karanlık mod (dark mode) odaklı, altın rengi detaylarla zenginleştirilmiş kullanıcı dostu bir arayüze sahiptir.

Platform; restoranlar, fırınlar ve marketler gibi işletmelerin gün sonu ürünlerini indirimli sunmasına veya bağışlamasına olanak tanır. İster gönüllü kurye olarak ihtiyaç sahiplerine yardım edebilir, isterseniz yürüyerek "Gel Al" seçeneği ile karbon ayak izinizi azaltıp sürpriz indirimler kazanabilirsiniz.

---

## ✨ Temel Özellikler

*   🛍️ **Fırsatlar (İsrafı Önleme):** İşletmelerin gün sonu veya son kullanma tarihi yaklaşan ürünlerini %65'e varan dev indirimlerle kurtarın.
*   🚲 **Gönüllü Kurye (Kurye Ol):** Kendi aracınız veya bisikletinizle, ihtiyaç sahiplerine bağışlanan gıdaları ulaştırarak iyilik zincirine katılın.
*   🚶‍♂️ **Çevreci Gel Al (Sağlık & Ödül):** Siparişinizi yürüyerek teslim alın. Attığınız adımlar ve yaktığınız kaloriler ölçülsün; karbon salınımını önlediğiniz için doğa dostu indirim kuponları kazanın.
*   💝 **Kumbara (Kolay Bağış):** Sadece birkaç tıklamayla "Sıcak Yemek", "Bebek Maması" veya "Aile Erzak Kolisi" bağışında bulunun.
*   📱 **QR Teslimat:** Güvenli, hızlı ve temassız sipariş teslimatları için kişiye özel QR kod sistemi.
*   🛒 **Akıllı Sepet:** Sepetinizdeki israfı önleme indirimlerini net bir şekilde görün ve kuponlarınızı kolayca uygulayın.
*   💻 **Çapraz Platform (Cross-Platform):** Web üzerinde React & Tailwind CSS ile çalışırken, tek tıkla Expo (React Native) kodunu kopyalayarak mobil uygulamasını anında derleyin.

## 🛠️ Kullanılan Teknolojiler

**Web Platformu:**
*   **React:** Kullanıcı arayüzü ve bileşen yönetimi.
*   **Tailwind CSS:** Hızlı, modern ve duyarlı (responsive) tasarım.
*   **Lucide React:** Minimalist ve şık ikon seti.

**Mobil Platform (Dahili Kod Çıktısı):**
*   **React Native & Expo:** iOS ve Android için native uygulama geliştirme.
*   **Expo Vector Icons:** FontAwesome5 ikon entegrasyonu.

## 🚀 Kurulum ve Çalıştırma

Projeyi kendi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

1. **Projeyi Klonlayın:**
   ```bash
   git clone https://github.com/kullanici-adiniz/gida-koprusu.git
   cd gida-koprusu
   ```

2. **Bağımlılıkları Yükleyin:**
   ```bash
   npm install
   ```

3. **Geliştirme Sunucusunu Başlatın:**
   ```bash
   npm run dev
   ```

4. **Tarayıcıda Görüntüleyin:**
   Tarayıcınızda `http://localhost:3000` veya terminalde belirtilen port adresine giderek uygulamayı inceleyebilirsiniz.

## 📱 Expo (React Native) Versiyonunu Deneme

Uygulamanın içindeyken sağ alt köşede bulunan **"Expo (React Native) Kodunu Al"** butonuna tıklayarak mobil uygulama kodunu kopyalayabilirsiniz. Kopyaladığınız kodu [Expo Snack](https://snack.expo.dev/) üzerine yapıştırarak mobil görünümü doğrudan tarayıcınızda veya telefonunuzda test edebilirsiniz.
